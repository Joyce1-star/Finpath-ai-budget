# FinPath 钱途 · 完整流程 Demo

单文件可交互原型：直接用浏览器打开即可，无需安装依赖、无需启动后端。

## 如何打开

双击 `index.html`，或右键用 Chrome / Edge 打开。

> 请保持 `index.html` 与 `assets/` 文件夹在同一目录，否则小理图片会加载失败。

## 目录结构

```
finpath-demo/
├── index.html
├── README.md
└── assets/
    ├── sleepy.png        # 未规划空态
    ├── thinking.png      # 对话 / 问卷 / 聊入口
    ├── happy.png         # 唤醒后 / 对话开心
    ├── celebrating.png   # 确认成功
    ├── worried.png       # 预留，网页暂未使用
    └── proud.png         # 预留，网页暂未使用
```

## 已包含功能

| 模块 | 内容 |
|------|------|
| 问卷测评 | 首次进入 11 题 onboarding，可跳过；画像页可重测 |
| 首页空态 | sleepy → 点击变 happy；开始规划 |
| 对话规划 | 收入 → 模式选择 → 预算方案卡 → 调整 chips → 确认 |
| 确认成功 | celebrating 庆祝页，回写首页已规划态 |
| 首页已规划 | 储蓄环、分配条、「和小理聊聊」进入调整 |
| 我的 | 昵称、心动方案槽、理财画像入口、小金库测算罐 |
| 画像详情 | 摘要、标签、维度条、关怀提示、重新测评 |

## 推荐演示路径

1. 问卷可点「稍后再说」跳过  
2. 空态拍一拍小理 → 「开始规划」  
3. 输入 `2500` → 「帮我排一版」  
4. 「就这样吧」→「定了」→「回到首页」  
5. 再点「和小理聊聊」进入调整流  
6. 「我的」看心动方案 / 小金库 / 画像

## Demo 说明（与完整产品差异）

本仓库为**前端完整流程演示**，对话为本地 mock，不连接真实 AI 后端。

以下为演示级简化，不影响主路径走通：

- 历史对话面板可打开，暂不支持点击恢复会话  
- 心动方案「切换」为示意 toast，不会改写首页数字  
- 无「清除本月方案」入口（刷新页面即可重置）

## 技术说明

- 纯 HTML + 内联 CSS/JS  
- 字体：Google Fonts（Fredoka / Manrope）；离线时会回退系统字体  
- 适配桌面手机框预览与窄屏真机视口
